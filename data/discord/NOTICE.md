# Discord data: no published license

The records in this directory are derived from the public list of detectable
applications that Discord serves at
`https://discord.com/api/v9/applications/detectable`. Discord uses the list to
show which game a user is playing.

Discord publishes no license for this list. Only factual identification data
is kept: application IDs, names, aliases, Windows executable names and paths,
and store IDs. Images, ratings, overlay settings and descriptive fields are not
kept.

These records are kept apart from the openly licensed data, in this directory
and in the release file `catalog-discord.json`, so that a consumer can leave
them out. Discord can ask for removal by opening an issue, and the data will be
removed in the next release.
